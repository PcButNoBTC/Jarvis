# Client trust — local first, then regions

## Goal

Be the **best option** in an untapped local market: clear, evidence-based, human-controlled.  
Profit without looking predatory. After local proof, the same system can expand region by region.

## Posture

| Do | Don’t |
|----|--------|
| Recommend only observed signals | Invent problems or fear pitches |
| One service, one scope, one price range | Kitchen-sink “AI transforms everything” |
| Human approves every outbound message | Auto-send sequences |
| Easy “no” | Fake urgency or shame |
| Client owns logins and data | Imply you control their accounts |
| Prove value locally first | Mass-launch regions before one paid loop works |

## Product hooks

| Hook | Where |
|------|--------|
| Client promise | Brief, portal, delivery packages |
| Fit checklist | Fit check before outreach |
| Soft CTA | Brief next step |
| Local pilot framing | Brief footer, operator tone |
| Verification gates | docs/VERIFICATION_GATES.md |

## Operator checklist before first contact

1. Run research → opportunity with factors  
2. Run **fit checklist** — only continue if fit  
3. Generate **client brief** (`share_text`)  
4. Human edits tone if needed  
5. Approve draft → send only with dual gate  
6. Log call outcome honestly (including “not a fit”)

## After local proof

Expand regions only when you have paid delivery, hours and revenue logged, and a client experience you would repeat.
